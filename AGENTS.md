# Masjidee project repositories

This public repository contains the Masjidee website and user documentation. Its sibling `/workspace/SmartLearningBuddy` contains the private application, shared backend and mobile packages. Treat them as one product with separate publication boundaries.

Use existing checkouts. Do not create a worktree unless explicitly requested. Preserve unrelated local work. Read the actual application behavior when verifying documentation, then write original user-facing guides; do not copy private source, internal setup files, credentials, backups or personal records into this public repository.

Use Node 24+, `npm ci`, `npm run build` and `npm run check:links` here. The site base is `/masjidee-site/`, docs are under `/docs/`, and dev/preview use port 4321. The app normally uses 5173; do not overwrite or stop unrelated app services.

Maintain Android invitation-only pilot and planned iOS labels. Never promise exact geofence timing, confirmed religious attendance, traffic-aware reminders or unreleased Bluetooth scanning. Keep privacy guidance aligned with privileged administrator diagnostic access and user-facing sharing controls. Do not invent public download URLs, support email addresses or app-store listings.

Website checks are automatic; Pages deployment is manual. Do not merge, enable Pages or publish the website without user authorization. Environment publication is separate from website deployment.
