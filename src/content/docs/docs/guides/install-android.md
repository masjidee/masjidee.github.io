title: Install the Android pilot
description: Install the trusted Masjidee pilot build provided by your organizer.
---
Masjidee’s Android pilot is distributed as an **APK installation file**. It is not currently a Google Play download.

## Before installing

- Get the file directly from your pilot organizer’s trusted channel.
- Confirm which version they want you to test.
- Keep your Android phone’s security updates current.

## Install

1. Download the APK on your phone.
2. Open it from your downloads or file manager.
3. If Android asks, review its permission to install apps from that specific source. Grant it only if you trust the file and source.
4. Follow Android’s installation prompts, then open **Masjidee**.
5. Sign in and choose your mosque.

Android and Samsung settings vary. **If a protection feature blocks installation, stop and send your organizer the exact message.** A blocked install does not by itself prove that the APK is defective. Do not disable broad account or device protections just to experiment.

## Update a pilot build

Use the newer build supplied by the organizer. Android normally requires a compatible application signature to update in place. If an update is rejected, ask for help before uninstalling: uninstalling can remove locally queued events and saved app information.

Your server-stored learning history is associated with your account, not the APK file. Sign in with the same identity after an update.

## iPhone

iPhone testing is planned. An APK cannot be installed on an iPhone. There is no current public iOS or TestFlight release.
