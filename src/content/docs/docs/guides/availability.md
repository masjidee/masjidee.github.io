---
title: What is available?
description: Distinguish the current Android pilot from planned capabilities.
---
These guides describe the current pilot implementation. Availability still depends on your installed version, phone permissions, mosque configuration and server setup.

| Capability | Status |
| --- | --- |
| Android app | Invitation-only pilot |
| iPhone app | Planned; no released or validated iOS pilot |
| Published prayer times and calendar categories | Available when configured by your mosque |
| Fixed-lead prayer departure reminders | Optional pilot feature |
| Manual check-in/out | Available with recording consent |
| Automatic geofence detection | Optional; phone/background behavior can delay or miss events |
| Personal attendance and permission-protected reports | Available when reporting is configured and processed |
| Student learning handoff | Available using your existing signed-in account |
| Latest two Friday sermons | Available when source discovery and usable official media links succeed |
| Qibla finder | Available with required foreground permissions; compass accuracy varies |
| Bluetooth-based location detection | Planned; not active scanning in this pilot |
| Traffic-aware departure calculations | Planned; current reminders use a fixed lead time |
| Automatic word-of-the-day or sermon lesson pushes | Future ideas, not promised current features |

The website does not distribute a public APK or offer an iPhone download. Ask your pilot organizer for the right build and access instructions.
