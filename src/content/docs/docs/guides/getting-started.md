## 1. Install your invited Android build

Ask your pilot organizer for the current trusted build. Follow the [Android installation guide](../install-android/). There is no public app-store release yet.

## 2. Sign in

Tap **Sign in securely**. The app opens the secure sign-in page in your phone’s browser. Choose an available sign-in method and finish any verification requested there.

Use the same identity you used for Smart Learning Buddy if you already have an account. Using a different Google or email identity can create a separate account; matching names do not combine accounts automatically.

## 3. Choose your mosque

Masjidee uses your existing organization association to help find your mosque. If a mosque has not been selected, choose **Find my mosque**. You can change it later through **☰ → Change mosque**.

[Read about home and visiting mosques](../choose-mosque/).

## 4. Explore the four main tabs

| Tab | What you will find |
| --- | --- |
| Home | Next congregation, Friday sermons and upcoming activities |
| Prayers | Published prayer times for the selected mosque |
| Events | Community activities, with available date views |
| Learn | The student learning library and assignments |

The **person icon** opens personal preferences. The **☰ menu** includes mosque selection, check-in/privacy controls, attendance reports, automatic detection/device status and Qibla direction. Mosque settings appear only for authorized people.

## 5. Enable only what you want

You can browse published schedules without turning on automatic check-ins. Reminders and background location have separate controls. Read [Privacy & permissions](../privacy/) before enabling them.
